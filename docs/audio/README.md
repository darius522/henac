# Listening examples

These are six 10-second, 32 kHz stereo excerpts and their four coded versions
from the paper's MUSHRA listening test. The WAVs were copied from the supplied
study assets without re-encoding or gain changes. Each directory uses the same
five filenames: `reference.wav`, `henac-23kbps.wav`, `henac-18kbps.wav`,
`dac-23kbps.wav`, and `heaac-24kbps.wav`.
