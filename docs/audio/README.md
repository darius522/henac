# Listening example

These five WAV files are copies of one 10-second excerpt and its coded
conditions from the paper's MUSHRA listening test. They were copied without
re-encoding or gain changes for this repository. The 3.5 kHz low-pass anchor
was generated by webMUSHRA and was not supplied as a standalone file.

The source music is [“champagne ardennes” by Misiaczek](https://freemusicarchive.org/music/Misiaczek/La_Fantaisie_des_Biches/champagne_ardennes)
(Free Music Archive track 31944), from *La Fantaisie des Biches*. It is
licensed under [Creative Commons Attribution 2.0 France](https://creativecommons.org/licenses/by/2.0/fr/).
The study material is a 10-second, 32 kHz stereo excerpt; the four coded WAVs
are reconstructions of that excerpt. These audio files are not covered by the
repository's MIT license for code and checkpoint weights.
